# Solver-IBM V2.0 阶段开发契约

状态：2026-09-27 经用户审核批准，作为 V2.0 阶段实施与验收依据。V1.0.0 发布包和标签保持不变；本阶段开发版本使用 V1.x.x，全部功能完成并通过验收后才发布 V2.0.0。

## 交付范围

同一个 `Solver-IBM.exe` 通过 JSON 配置使用以下能力；三项应可分别启用、两两组合或同时启用。

1. 流固共轭传热：流体温度输运、固体内部导热、理想热接触、强制对流和 Boussinesq 自然对流。流体与不同固体分别使用常数物性，支持恒温、指定热流、绝热、外界对流换热和固体体积热源。
2. 自由液面：水箱晃荡、溃坝、物体入水、液体注入和排出；支持常量表面张力及每个固体的固定静态接触角。仅求解液体，气体按固定环境压强处理；不含气相流动和相变。
3. 动态 STL：多个刚体可分别使用匀速平移、定轴旋转、正弦往复和带时间戳轨迹，并可组合平移和旋转。本阶段不求解变形、碰撞接触或受力后的自由运动。

新增功能支持 `FP32 × D3Q19/D3Q27 × SRT/TRT × none/Smagorinsky` 共 8 种流动组合。未启用新增功能时，保留 V1.0.0 的 FP16S/FP32 共 16 种组合、接口语义和严格回归基线。

## 物理与接口约定

- 自然对流的重力、参考温度和热膨胀系数与其他体积驱动力分开配置。Smagorinsky 热输运显式配置湍流 Prandtl 数。
- 自由液面及固体干表面可设绝热或环境温度/换热系数；湿润流固面采用共轭换热。同一生效表面不得同时强制冲突的 CHT、恒温和定热流条件。
- 浸没固体持续加热使用固体体积热源或独立加热边界，并计入热量收支。
- 新的多材料或动态对象不支持相互穿透、运动碰撞或穿越计算域。旧单相静态配置仍保留 STL 并集和原有受力归属规则。
- 运动固体的温度随材料移动并保留历史；再体素化不得重置温度或把热量遗留在旧位置。
- 注入/排出条件记录实际离散质量和焓流。旧 `equilibrium` 语义保持，不直接改名为通用自由液面出口。
- 初始液体支持基本区域和封闭 STL 体积掩膜。STL 局部热区域使用物体坐标，随物体移动。
- 输出增加温度、填充率、相态、材料/物体 ID、姿态、速度、受力、力矩、液位、干湿面积、质量收支和显热收支。热量平衡不冒充包含驱动功和黏性耗散的完整机械—热总能量守恒。

## 验收体系

专项算例包括：

- 一维温度扩散、多层材料瞬态/稳态导热、加热固体通道、差分加热方腔及带导热壁变体。
- 静水、静滴、60°/90°/120°壁面液滴、小振幅和有限振幅晃荡、公开溃坝、已知流量和温度的充排液。
- 平移、旋转、往复、启停、轨迹表、多体，以及非均匀温度固体的闭合运动周期。
- 规定速度物体入水/出水、热固体反复穿越液面，以及带加热移动物体和温差充排液的综合容器。

三项功能有 7 种非空组合；与 8 种 FP32 流动模型组合相乘，至少执行 56 个兼容性短算。物理精度由专项基准验证，不能用矩阵“能运行”代替。

拟定目标：光滑热扩散温度相对 L2 误差不高于 2%，稳态界面热流误差不高于 3%；自然对流平均 Nu 误差不高于 5%；静滴 Laplace 压差误差不高于 5%，接触角偏差不高于 5°；小振幅晃荡主频误差不高于 3%；闭合液体质量残差不高于初始质量的 0.1%；显热收支残差不高于约定热量标度的 0.5%；随体温度相对同时间静止导热参考经姿态变换后的 L2 误差不高于 2%。公开溃坝等强非线性实验采用预先固定的测点、时间窗、网格序列和参考数据。

各算例在运行前固定参数、范数、时间窗、网格和参考数据。未达标时修复或提交范围/指标变更审核，不在看到结果后选择有利窗口或自动放宽阈值。

## 工程和发布规则

Mac 编辑、提交和推送；NUC 拉取、构建和运行。构建和结果记录 Git 提交、源码树、EXE SHA256、设备、命令及退出状态。字段变更同步解析器、schema、手册、示例和适用测试。

最终发布包含源码、构建入口、程序、手册、全部示例及 STL/轨迹输入、验证脚本、必要参考数据、原始报告、交接文件和 SHA256 清单。正式标签及 `package/V2.0.0` 仅在全部验收完成后建立，不覆盖 V1.0.0。

参考基准包括 de Vahl Davis 差分加热方腔、ComFLOW/MARIN 溃坝实验，以及适用于异质材料守恒能量方程的公开研究。外部参考文件记录来源、单位和哈希。

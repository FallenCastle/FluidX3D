# P3 数值模型运行时选择：确定的实施契约

2026-09-22。用户已选择完整三维模型组合、仅做数值模型选择、开放 Cs/Λ。基于 P2 `33f158c`，工作分支 `codex/config-runner-p3`，新构建名 `config-runner-p3`；保留 P2 EXE 作独立基线。设计先于实现提交。

## 输入与兼容

同一 EXE 支持 D3Q19/D3Q27 × SRT/TRT × none/smagorinsky × FP16S/FP32，共 16 种组合。仍限单 GPU、命令行、静态单相；继承 SI/格子单位、STL、体积力、固定位置运动壁面、受力及分析和参数扫描。

```json
"solver": {
  "lattice": "D3Q27",
  "collision": "TRT",
  "storage": "FP32",
  "turbulence": "smagorinsky",
  "smagorinsky_constant": 0.17,
  "trt_magic_parameter": 0.1875
}
```

四个模型字段均可省略，默认保持 D3Q19/SRT/FP16S/smagorinsky。schema_version 仍为 1。Cs/Λ 无量纲，不随 SI 换算。字符串大小写严格；未知字段和值拒绝。

- `smagorinsky_constant`：本轮支持 `0 < Cs <= 1`，仅在 smagorinsky 下允许；关闭用 `turbulence="none"`，不以 Cs=0 隐式关闭。默认 `sqrt(0.76421222/(18*sqrt(2)))`，约 0.17326595533835415。默认路径保留原内核浮点常量 `0.76421222f`，避免兼容性漂移。自定义值产生 `18*sqrt(2)*Cs²`，必须能用正有限 FP32 表示。
- `trt_magic_parameter`：本轮支持 `0 < Λ <= 1`，仅在 TRT 下允许，默认 3/16。按现有 TRT 公式由偶松弛率算奇松弛率；开启 Smagorinsky 时使用局部有效偶松弛率。检查基础松弛率可表示且在 (0,2) 内。以上参数上限是本轮软件支持范围，不宣称普适物理边界；通过输入检查不保证所有场景稳定。
- 非启用模型的显式参数直接报错，不忽略。resolved 记录实际模型、启用参数、实际 FP32 系数、基础偶/奇松弛率；Smagorinsky 的局部有效值并非全域常数。

## 实现结构

新增不依赖编译宏的 SolverOptions，按值传入并冻结于 LBM/LBM_Domain。不增加逐格点运行时模型分支，而是在创建实例时生成 OpenCL 模型宏及系数。上游所有方向/邻居/平衡分布/碰撞/受力内核使用同一实例的选择。Q、权重、传输数、实际缓冲区分配、最大单缓冲检查、预算和日志同步。

设备字段为 `Q*storage_bytes+29` B/cell：D3Q19 为 67/105，D3Q27 为 83/137；主机字段仍为 29 B/cell，另计并集与几何/统计。保持预算原有最近整数取整语义。capabilities 的 lattice/collision/turbulence 改为支持列表，新增完整 defaults、参数规则和按模型的字节表；保留旧 device_bytes_per_cell 作为默认 D3Q19 的兼容字段。

配置、schema、示例、扫描、resolved、状态/完成记录和日志一起更新。旧配置输出数值保持；P1 的“不支持 TRT”负例换为真正不支持的值。新模型组合明确限单设备，未实现物理扩展保持编译保护。

## 验收方案

1. 同一最终 EXE 遍历 16 组合：周期保持性、实际 DDF 容量、模型日志/元数据、STL+体积力+运动壁面+受力小算例；采样不扰动流场；保存同网格短算时间和字段字节量。性能结果只描述该设备及该算例。
2. FP32 的 8 个模型组合均运行 Poiseuille/Couette，H=8/16/32，固定 tau、Re=4 的扩散尺度；沿用速度 L2/Linf <3%、壁面力误差 <4%。报告实际细化结果，不预设严格阶数。FP16S 运行相应对照并记录误差，保留已有量化限制，不把其全部场景视为满足 FP32 精度阈值。
3. Cs/Λ 非默认值、非法值、错误适用模型；Cs 改变高剪切场应改变结果；TRT 在 Λ=(tau-0.5)^2 且无亚格子时，与 SRT 做允许舍入误差的退化等价对照；Smagorinsky 开/关在零剪切均匀流保持性对照。
4. D3Q27/TRT 的 SI 等价、探针/受力、快照及模型参数扫描；至少一个三维非均匀周期算例激发体对角方向，避免仅靠一维通道验证 D3Q27。
5. 旧 P1/P2、运行时存储验收继续通过；旧默认 P2 EXE 与新 EXE 的 STL 组合算例严格数组/统计一致，Boeing 原基线一致。每个宣称支持的组合都必须有成功记录，不能隐藏失败。

全部编译和求解在 NUC，Mac 仅编辑与报告整理。经 Git 提交推送后 NUC 拉取构建，产物及日志保留身份，结束检查并关闭本轮 SSH/代理。

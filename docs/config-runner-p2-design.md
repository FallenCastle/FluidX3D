## 核心输入与采样

保留 `schema_version=1`，新增可选 `analysis`，不提供该项的输入保留原有采样行为。

```json
"analysis": {
  "every": 10,
  "start_step": 100,
  "statistics": true,
  "probes": [
    {"id": "wake", "position": [40.5, 24.5, 20.5]}
  ]
}
```

- `every` 为正整数，缺省取 `run.monitor_every`；`start_step` 缺省为 0，必须位于 [0, run.steps]。采样只发生在 `start_step + k*every <= run.steps` 的步数，事件调度准确到达这些时刻。
- `statistics` 为布尔值，缺省 true。关闭时仍保存采样 CSV，只不累计时间统计。
- `probes` 缺省为空。ID 非空且唯一；position 采用配置长度单位。取最近的格点中心，同距时取较大索引；域为半开区间 [origin, origin+实际长度)，域外位置拒绝，不自动回绕或夹取。
- `resolved-config.json` 记录请求坐标、格点索引、实际采样坐标及采样时序。体素化后发现探针落入固体则报错，不把固体值当成流场值。
- prepare-only 完成探针位置与固体检查，但不产生时间统计样本。正常计算的初始状态只有在 start_step=0 时才参与统计。最终步不在采样时序上时，不插入不等间隔样本；最终场仍由原有 VTK/monitor 输出覆盖。
- 所有新增对象仍执行未知字段、重复键、类型、有限值和非法组合检查。

## 输出和物理含义

新增 `probes.csv`、`analysis.csv` 与开启统计时的 `statistics.json`。

- 探针 CSV：step、time、ID、实际坐标、rho、速度三分量、speed、表压 p。
- 全域分析 CSV：非固体格点数、总质量、空间平均 rho/u/p、平均速度模及总动能。包括 equilibrium 边界格点；是否为固体按边界类型精确判断。
- 时间统计采用双精度 Welford 累积，保存样本数、首末采样步、均值和总体标准差。分别统计各探针量和全域分析量，不隐式分配全场均值/方差数组。总体标准差使用 N 为分母；单样本标准差为 0。
- 质量和动能包含格点体积。格子模式 dx=dt=reference_density=1；SI 模式分别用 kg、kg/m³、m/s、Pa、J 和 s。CSV 列名/配套元数据明确单位。
- 表压以 `fluid.rho` 为参考密度，保持独立于 `initial.rho`：`p=(rho_l-rho_fluid_l)/3 * reference_density*(dx/dt)^2`。该量是等温 LBM 的密度扰动压力，不解释为绝对热力学压力。
- 新增可选 VTK 字段 `p`，默认字段仍为 u/rho/flags，与探针压力使用相同参考及单位。
- 统计量溢出或出现非有限值时明确失败，不向 JSON 写 null 冒充有效结果。CSV 的 ID 正确转义，支持中文与空格。

## 批量参数研究

新增 Python 标准库脚本，分成生成和执行两个显式动作；每个算例启动独立求解器进程，顺序执行。

- 扫描描述文件包含 `schema_version`、基础配置路径和有序参数轴。每轴为一个 JSON Pointer 及非空 values 数组；按笛卡尔积生成。
- 仅替换基础配置中已存在的字段或数组元素，拒绝不存在的路径、重复/祖先冲突路径、无效指针和空扫描。用零填充序号作为目录名，不把任意参数值直接放进文件名。
- 生成目录保存基础配置与扫描描述快照、STL 资产副本、生成配置、参数映射和 SHA256 清单。生成配置的 STL 路径指向该批次资产，避免挪动配置后相对路径失效；拒绝覆盖已有非空输出目录。
- 执行模式仅在 Windows NUC 使用，复用 `run-nuc.ps1` 的构建身份验证、EXE 快照、独立结果目录、退出码/完成步数检查与超时清理。整个批次固定同一构建和 EXE 哈希。
- 汇总 JSON/CSV 包含每个组合的实际参数、运行状态、结果目录、完成步数、耗时和统计结果位置。单项失败继续记录其它组合，批次最终返回非零。重新执行创建新的批次记录，不覆盖原运行结果。
- 本轮不加入表达式求值、自定义脚本执行、并行 GPU 调度或自动收敛停止。用户通过配置定义计算，通过扫描文件定义参数组合。

## 验收

在 NUC 对最终同一 EXE 哈希验证：

1. P1 无 analysis 输入回归：周期流、SI 等价输入、几何变换和并集、局部边界、Boeing/Ahmed 短算。若扩展固定物理能力导致存储或数值路径变化，须明确记录并重新对照，不直接放宽旧标准。
2. 均匀周期流探针与 VTK 同步一致；SI/格子速度、密度、表压及统计按单位因子对应。
3. 用非整除间隔与非零 start_step 检查样本数、采样步、最终输出；用 CSV 独立计算均值/总体标准差，与在线统计对照。
4. 使用非均匀初场演化检查统计具有非零方差，防止仅靠常量场掩盖累计算法错误。
5. 拒绝域外、固体探针、重复 ID、错误字段和非法时序；检查 prepare-only 无时间样本及中文/空格路径。
6. 至少 2×2 参数扫描，验证生成组合、资产快照、相对路径、同一 EXE 身份、逐项结果汇总以及失败组合的非零批次状态。
7. 报告新增统计的主机开销和有/无采样的运行耗时；若新增 FORCE_FIELD，单独记录设备存储与计算开销。

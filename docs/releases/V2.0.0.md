# Solver-IBM V2.0.0 发布说明

Solver-IBM V2.0.0 在 V1.0.0 配置驱动求解器上增加三类可组合能力：流固共轭传热、单液相自由液面和多个 STL 的规定刚体运动。程序仍为单 GPU 命令行 `Solver-IBM.exe`，保留 FluidX3D 上游署名、许可证和第三方许可。

正式代码由 Git 标签 `v2.0.0` 固定，正式包位于：

```text
F:\01-Project\Opensource\01-FluidX3D\package\V2.0.0
```

V1.0.0 的标签与 `package/V1.0.0` 保持不变。

## 新增能力

### 流固共轭传热

- 流体温度对流扩散、固体内部导热和理想流固热接触。
- 流体及多个固体分别使用常数密度、比热和导热系数。
- 强制对流和 Boussinesq 自然对流；Smagorinsky 模式可设置湍流 Prandtl 数。
- 恒温、指定热流、绝热、外界对流换热和固体体积热源。
- 运动固体的非均匀温度随材料坐标移动；体素重映射保持固体热历史。

### 自由液面

- 水箱晃荡、溃坝、物体入水/出水和液体注入/排出。
- 常量表面张力；每个域固壁或 STL 可指定固定静态接触角。
- 盒、球和封闭二进制 STL 初始液体区域。
- `liquid_inlet`、`open_outlet` 及离散质量/显热焓流记录。
- 气体按固定环境压强处理；不求解气相流动或相变。

### 动态 STL

- 多个刚体分别设置匀速平移、定轴匀速旋转、正弦往复或带时间戳轨迹。
- 平移与旋转规律可组合，并支持启停时刻。
- 输出对象 ID、姿态、线/角速度、力、力矩、温度范围和显热。
- 当前运动由配置预先给定，不包含变形、碰撞接触或受力后的六自由度响应。

新增功能要求 `solver.storage="FP32"`，覆盖 D3Q19/D3Q27 × SRT/TRT × none/Smagorinsky 共 8 种流动模型。没有启用热、自由液面或动态 STL 的旧配置继续支持 V1.0.0 的 FP16S/FP32 共 16 种组合。

## 示例与结果

`cases/configs/` 包含可直接运行的专项与组合配置，包括热扩散、多层导热、加热固体通道、自然对流方腔及导热壁、静水、静滴、三种接触角、晃荡、溃坝、充排液、STL 液体掩膜、平移/旋转/往复/时间表/多体、物体入水、随体温度闭环以及三项综合容器。小型二进制 STL 位于 `cases/configs/assets/`，MARIN 参考数据位于 `cases/configs/reference/`。

新增 VTK 字段为 `T`、`material`、`object`、`phi`。新增 CSV 为 `free-surface.csv`、`surface-levels.csv`、`boundary-flux.csv`、`conservation-budget.csv` 和 `object-motion.csv`。完整字段、单位和方向约定见[中文使用手册](../user-manual-zh.md)。

| 验收组 | 结论 | 代表性结果 |
|---|---|---|
| 热与共轭传热 | 通过 | 光滑扩散 L2 0.105%；强制对流 L2 0.477%；多层界面热流误差 0.230%；Ra=1000 平均 Nu 误差 0.353% |
| 自由液面 | 通过 | 静水压差误差 0.000037%；静滴 Laplace 压差误差 1.508%；60°/90°/120° 接触角误差 1.980°/2.304°/2.855°；小振幅晃荡主频误差 0.900% |
| 运动与热历史 | 通过 | 闭合周期随体温度 L2 0.0117%；平移、旋转、启停、轨迹表及多体姿态逐项匹配 |
| 强非线性场景 | 通过 | MARIN 四液位归一化 RMSE 0.103；H1/H2/H3 到达时间误差 0.05/0.06/0.12 s；物体入水产生非零动态受力 |
| 综合守恒 | 通过 | 温差充排液综合容器质量残差约 `2.7e-14`，显热残差约 `1.1e-8`；其他闭合自由液面质量残差均不高于 0.1% |
| FP32 功能矩阵 | 56/56 通过 | 7 类非空功能组合 × 8 种流动模型 |
| V1 兼容回归 | 通过 | P1、P2、FP16S/FP32 存储、P3 全矩阵和参数扫描五套回归 |

物理精度阈值、固定参数和逐项证据见 [V2.0.0 正式验收记录](../validation/solver-ibm-v2.0.0-2026-09-27.md)。公开溃坝采用 SPHERIC Test 2 / MARIN 数据；包内保留压缩后的液位 CSV、来源说明及原始文件哈希，不把网页或外部归档内容冒充本项目结果。

## 已知边界

- 单 GPU、三维、低马赫 LBM；规定运动表面速度限制为不超过 0.05 cell/step。
- 自由液面只求液体，气体为固定环境压强；没有气相惯性、密闭气体压缩、相变或动态接触角。
- 热物性为常数，流固接触为理想热接触；没有接触热阻、辐射、温度依赖物性或相变潜热。
- 动态 STL 必须保持刚体体素数，不能相互穿透、碰撞或越界；诊断受力不驱动物体运动。
- 显热收支不包含机械功和黏性耗散，不能解释为完整机械—热总能量守恒。
- 公开溃坝和所列专项基准限定于固定网格、时间窗和测点，不能替代任意工程尺度的网格独立性与实验确认。

V2.0.0 的范围、输入和限制以本说明及[用户手册](../user-manual-zh.md)为准；上游 README 中的图形、多 GPU或其他示例不自动成为 Solver-IBM 配置接口能力。

# Solver-IBM V1.0.0 发布说明

Solver-IBM V1.0.0 是本项目第一个正式版本，基于 FluidX3D 改造为配置驱动命令行求解器。通过同一个 `Solver-IBM.exe` 与 JSON/STL 输入选择受支持算例；产品命名不表示新增了当前接口尚未实现的浸入边界算法。

正式标签为 `v1.0.0`，统一版本定义为 `src/version.hpp`。原项目仓库和工作目录路径保持不变。上游 FluidX3D 作者署名、许可证、第三方代码许可证及模型来源记录随包保留。

## 发布内容

固定归档位置：`F:\01-Project\Opensource\01-FluidX3D\package\V1.0.0`。

```text
V1.0.0/
├── source/                       正式标签对应的原样 Git 源码快照
├── source.git.bundle             可克隆的 Git 数据及发布标签
├── bin/
│   ├── Solver-IBM.exe            本版本正式程序
│   └── build.json                原始构建身份记录
├── docs/                         用户手册、发布说明、交接和历史设计文档
├── cases/
│   ├── configs/                  可移植的算例及参数扫描配置
│   └── models/                   14 类模型的已有输入、来源和处理记录
├── tests/
│   ├── scripts/                  全套测试和配套运行脚本
│   ├── reference/
│   │   ├── boeing-baseline/       run.json 及必要 VTK
│   │   ├── fp16-reference/        固定 FP16S 输入、几何及必要结果
│   │   ├── p1-build/              历史对照 EXE 与构建记录
│   │   ├── p2-build/
│   │   └── fp32-diagnostic-build/
│   ├── historical-inputs/        原样保存的历史正向、负向测试输入
│   └── reports/                  历史与本次发布验收证据
└── manifest.json                 版本、提交、构建身份、文件大小及 SHA256
```

`manifest.json` 记录除自身外的包内文件校验值。`bin/build.json` 保存生成 EXE 时的实际路径和工具链，因此其中的历史绝对路径不是包内资源的定位规则。源码完整性与发布标签对应；`source/` 不包含运行中间产物或 `.git`。

模型资产包括 Boeing、Ahmed、NASA CRM、Concorde、X-Wing、TIE Fighter、径向风扇、涵道风扇、Cow、Space Shuttle、Starship、Cessna、Bell、Mercedes F1。归档资产不表示全部模型均已获得可运行的 JSON 或精度验收：Cessna/Bell 仍有部件制备工作，Mercedes STL 为未清理草稿。保留来源元数据和素材原目录结构。

保留必要的回归基准流场，**不包含全部历史运行产生的 VTK**。历史无效 JSON、损坏 STL、缺文件测试等输入按原始字节保存；它们用于追溯和预期失败测试，不应作为普通成功算例运行。

## 支持能力

| 范围 | V1.0.0 内容 |
|---|---|
| 运行形式 | Windows NUC 命令行，单 OpenCL 设备 |
| 数值模型 | D3Q19 / D3Q27，SRT / TRT，Smagorinsky 开/关 |
| 存储 | FP16S / FP32 运行时选择；算术为 FP32 |
| 模型参数 | 可配置 Smagorinsky 常数 Cs、TRT 魔术参数 Λ |
| 单位 | 格子单位、SI；直接黏度或 Re 与参考尺度 |
| 计算域 | 长方体、显式格点或允许的尺度/预算推导方式 |
| 几何 | 二进制 STL，fit/scale、旋转、平移，多物体静态并集 |
| 边界 | periodic、no_slip、equilibrium、固定位置 moving_wall，区域和优先级 |
| 驱动和分析 | 常量体积力、探针、压力、分组受力、时间统计 |
| 输出 | VTK、CSV、JSON，输入快照和构建/运行追溯 |
| 批量运行 | 参数笛卡尔积生成、资产快照、顺序执行及汇总 |

默认模型是 D3Q19 + SRT + Smagorinsky + FP16S。关闭亚格子模型或切换精度必须在配置中明确指定；全部字段、范围和默认值见 [用户手册](../user-manual-zh.md)。

## 与开发版本的整理变更

- 对外产品名称统一为 Solver-IBM，正式程序为 `Solver-IBM.exe`。
- `--version` 查询产品版本；`src/version.hpp` 为统一版本来源。
- 构建与运行入口适配新名称，当前 BuildName 为 `solver-ibm-v1.0.0`。
- 新增版本化发布归档、包内资源定位和包运行/验证入口。
- 文档区分当前产品契约与 P0–P3 历史记录；旧对照 EXE、原始报告和失败记录不改写为新版本身份。

此次整理不扩展边界算法或物理模型。正式包在 NUC 使用所打包 EXE 进行发布验证，结果以对应报告中的实际哈希和状态为准。

## 运行与重建

首先运行 `bin/Solver-IBM.exe --version`、`--capabilities` 和 `--list-devices`。使用 `source/scripts/run-package.ps1` 指定 `-PackageRoot`、`-ConfigPath`、包外 `-WorkspaceRoot`、`-CaseName` 和 `-DeviceId`；完整可复制命令见 [手册第 2.5 节](../user-manual-zh.md#25-使用正式发布包)。新计算结果写在包外，不改变正式归档。

修改算例时复制配置到新的工作目录并检查 STL 相对路径。需要重建时先克隆 `source.git.bundle`，检出 `v1.0.0`，再在 NUC 执行 `build-nuc.ps1`；不能直接把无 `.git` 的 `source/` 当成现有构建脚本需要的 Git 工作区。

## 验证依据与当前限制

历史 P3 验证覆盖 16 模型组合、周期流、Poiseuille/Couette、三维剪切波细化、SI、静态 STL、运动壁面、受力、快照和旧版本回归。历史报告中 48 组 FP32 通道达到其阈值；FP16S 的 48 组中有 32 组未达到相同速度/受力阈值。这是存储精度适用边界，不能把 16 种组合都能运行解释为所有参数下均有相同精度。

历史依据见 [P3 验收记录](../validation/config-runner-p3-2026-09-22.md)。该记录对应旧 EXE，不能代替本次重新构建后的发布验收。

**2026-09-27（北京时间），V1.0.0 新二进制完成全部五套发布验收，各套件退出码为 0，聚合状态为 `succeeded`，运行前后候选包内容一致。** P1 为 29 次调用；P2 为 25 次调用、6 个剖面；存储专项为 14 次调用及两组合扫描；P3 为 214 次调用、16 模型组合、96 个剖面及 16 组合扫描；参数扫描专项为 9 项检查及两组合运行。正常包运行入口与 Ahmed 零步预处理均通过。次数包含按预期报错的负向测试，不表示每次求解器调用都返回 0。

新 EXE 的 SHA256 为 `706e1bd99c2e0d9cb326be828266df33b6979651b2f25e58d118ee6aed471a5c`。本次重新执行了完整模型矩阵，FP32 的 48/48 个通道剖面达到阈值，FP16S 仍有 32/48 个剖面未达到相同阈值；后者作为已知精度限制保留，不能解读为全部 96 个剖面通过同一精度标准。

具体身份、阈值和数据见 [V1.0.0 正式验收记录](../validation/solver-ibm-v1.0.0-2026-09-27.md)。包内完整报告约定为 `tests/reports/release/full-acceptance.json` 和 `tests/reports/release/suites/<name>/report.json`；最终候选包的再次校验由 `tests/reports/release/package-verification.json` 单独记录，以该文件的实际状态为准。源码最终提交由根目录 `manifest.json` 标识，原始构建提交仍保留在 `bin/build.json`。完整回归在候选目录执行，本文不把后续归档位置核验表述为已经再次重跑五套测试。

其他限制：

- `equilibrium` 同时固定密度和速度，尚无独立压力出口/零梯度出口。
- `moving_wall` 位置固定且速度切向；不支持通过本配置接口移动或旋转 STL。
- 尚未开放图形模式、自由液面、热模型、多 GPU、断点续算及自动收敛停止。
- Boeing/Ahmed 当前证据包括回归和短算，不能等同于完成工程阻力精度验证。
- 上游介绍中已有但当前 JSON 未开放的功能，不属于本版本接口承诺。

# Solver-IBM V2.1.0 发布说明（开发版）

**状态：开发版本（`release_status="development"`）。** 依据用户决策 D5（2026-10-15），V2.1.0 验收通过后先作为开发版本试用，不立即建立 `package/V2.1.0` 正式包与 `v2.1.0` 标签；正式封版由用户在试用期结束后另行决定。本文随正式封版更新状态字段。

Solver-IBM V2.1.0 在 V2.0.0 全部能力之上增加**断点续算（Checkpoint/Restart）**：长算例按步数间隔保存完整数值状态，进程崩溃、被终止或正常结束后从最新有效检查点恢复续算，并支持延长 `run.steps`/`run.duration` 继续计算。V2.0.0 的 V1/V2 全部功能、接口与数值行为不变（禁用检查点时输出与 V2.0.0 同环境逐字节一致，见验收记录基线对照）。

## 新增能力

### 检查点保存与恢复

- 配置 `run.checkpoint_every`（保存间隔步数，0/缺省 = 禁用）与 `run.checkpoint_keep`（保留个数，默认 2）；正常完成时额外保存终态检查点。
- `Solver-IBM.exe --config FILE --output DIR --restart` 从 `DIR/checkpoint/` 的最新有效检查点恢复；`run-nuc.ps1 -RestartFromRunId <RunId>` 与 `run-package.ps1` 同名参数走标准运行入口，本次运行有独立 RunId 日志与 `run.json` 溯源块，结果续写原 results 目录。
- 保存状态覆盖全部跨步数值状态：DDF（FI，FP16S/FP32 原始字节）、rho/u/flags、力场 F、自由液面（phi/mass/massex/接触角）、热输运（T/material/物性三场）、动态几何（object_id 与随体热历史三数组）、守恒预算与目标、统计累计（Moments）、输出文件字节位置与 VTK 帧清单。

### 一致性保证（同机、同 GPU、同驱动、同构建）

- 续算与不间断运行的数值状态（检查点字段逐字节）与数值输出（共同调度步的 CSV 行、VTK 帧、`statistics.json` 逐字节）一致；验收判据与冻结阈值见 `docs/validation/checkpoint-tolerance-thresholds.md`。
- 检查点提交为 W1–W6 阶段协议：临时目录写入 → 逐文件 `FlushFileBuffers` → SHA256 重读校验 → rename 原子发布（提交点）→ 提示指针 → 保留清理。进程在任意时刻被强杀，已提交检查点保持可用；恢复时按记录截断 CSV 残留半行、清理杂散 VTK 帧，修复可重入。
- 加载器按步数新到旧全量校验候选；结构性损坏候选移入 `quarantine/` 并回退次新；身份/配置契约不符直接拒绝且不修改任何既有输出。

### 配置与兼容契约

- 恢复要求配置与原运行完全一致，白名单仅允许 `run.steps`/`run.duration`（解析后目标步数单调不减）与 `run.checkpoint_every`/`run.checkpoint_keep`；`steps` 与 `duration` 不可互换。
- STL 资产按封存 `manifest.json` 哈希核验：内容变化拒绝；原文件缺失自动回退 `inputs/assets/` 快照并记录 `used_snapshot_assets`。每次重启的实际配置留存 `inputs/restart-configs/`，`completion.json.restarts[]` 记录重启链。
- 三层兼容身份：检查点格式版本（当前 2）、产品版本、数值内核身份（内核源 SHA256，同源码重建放行并警告）；跨设备允许加载，逐位一致仅对同设备成立。
- 专用退出码：3 = 无可用检查点，4 = 检查点保存失败，5 = 兼容性/契约拒绝（1 仍为一般错误）。
- 输出目录 `run.lock` 单写者保护（PID 记录；`--restart` 可破除已死进程残留锁）。

## 资源口径

单检查点 ≈ `N × (q×ddf字节 + 17)` + 模块附加（自由液面 +16、热 +13、动态 +1、力场 +12 B/cell）+ 动态热历史 24 B/样本；FP32 D3Q27 全模块约 171 B/cell。提交峰值磁盘 ≈ `(keep+1)×单检查点 + quarantine`；启动预检空间不足即拒绝启用。检查点加载含逐字段回读校验（防御纵深）。

## 已知边界

- 检查点不跨产品版本兼容；数值内核身份变化（改内核源码重建）拒绝加载。
- 逐位一致承诺限于同机、同 GPU、同驱动、同构建；跨设备续算允许但不承诺逐位一致。
- 断电持久性按 Windows 缓冲 I/O 刷盘语义设计（文件级 `FlushFileBuffers` + NTFS 日志 rename；Windows 无用户态目录 fsync），经阶段故障注入与强杀测试验证进程崩溃窗口；未做真实断电硬件测试。
- 磁盘满等保存失败终止运行（退出码 4），旧检查点保持可用；不静默降级。
- `checkpoint/`、`quarantine/`、`run.lock` 为运行产物，随结果目录归档，不进源码仓库与正式包清单。
